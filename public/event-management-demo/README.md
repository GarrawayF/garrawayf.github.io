# Garraway F イベントアプリ｜デモ版

## 現在の入口

- `index.html`：試験用の申請画面へ進む入口。送信内容は非公開の試験用台帳へ保存されます。
- `concierge.html`：共有パスワード入力画面へ進む、関係者用の入口。
- 認証と実データの処理はGoogle側で行います。この公開リポジトリにパスワード、個人情報、実案件、管理用シートのURL・IDは保存しません。
- 申請送信と運営管理画面への反映を確認済みです。共有パスワード入力後の一覧・保存と、Googleにログインしていない端末での表示は確認待ちです。
- 正式な予約・最終承認・同意取得ではありません。最終同意書・ヒアリング項目の正式統合は未完了です。主催者への承認通知メールは送信しません。運営向け状況通知は別機能です。
- カタログは最終確認後に入口から接続します。

## 共通の6工程

01 事前申し込み／02 詳細すり合わせ／03 承認／04 開催準備／05 当日／06 結果報告

## 保存しない確認画面

- `application.html`：旧入力デモ。入力の確認のみで、送信・保存は行いません。主ナビには掲載していません。
- `staff.html`：既存v33の3役割を維持した、架空6案件の表示専用プレビュー。役割切替は認証・権限変更ではなく、実際の承認・保存・通知は行いません。
- これらの確認画面には、実際の個人情報や機密情報を入力しないでください。
