- 実際の申請受付、送信、保存は行いません。

## イベント管理の確認画面

`staff.html` は既存 v33 の3役割画面を維持した、公開用の架空データ版です。

- コンシェルジュ・女将・トヨタが同じ6つのサンプル管理票を確認できます。
- 実在の人物・団体・実案件・Google Sheets の識別子や接続先は含みません。
- 表示切替は本人認証や権限の変更ではありません。実際の承認・保存・通知は行いません。
- 外部通信・フォーム送信・端末保存は行わず、再読込で表示状態が戻ります。
- 本番の実データを扱うには、別途サーバー側の認証・権限制御が必要です。
- 申請者用画面は引き続き `index.html` / `application.html` です。
