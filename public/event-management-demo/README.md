# イベント申請・管理の確認用デモ

架空の6案件で、書類確認から審査、開催準備、当日、終了報告までを試せます。

- 実際の申請、メール送信、予約、保存、他の人との状態共有はありません。
- 役割切替は画面比較用です。実運用の認証・権限管理ではありません。
- 入力フォームの確認結果は管理画面へ登録されません。
- 全データはブラウザーのメモリー内だけです。再読み込みで初期化されます。
- ソースと案件はすべて公開されるため、実データや連絡先、秘密情報を追加しないでください。

管理画面の操作・モデル・通知・未送信メール文面を自動テスト済み。ブラウザー実描画の検証は別途必要です。

公開ページは `public/event-management-demo/` だけで完結します。既存HP、ドメイン、DNS、メール設定は変更しません。
