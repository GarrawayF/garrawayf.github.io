# 主催者申請と関係者専用入口の確認版

公開内容は、入口、主催者の架空入力フォーム、関係者専用入口の準備状況案内だけです。

- コンシェルジュ用の管理コード・案件データ・内部メモは、この配信パスには含めません。
- 関係者専用の案内ページは公開情報だけで、認証済み管理画面ではありません。
- 認証と非公開保存先は未接続です。疑似ログインやブラウザー側の役割切替は設けません。
- 申請フォームは確認用で、実際の受付・送信・保存はしません。
- 本番の管理側は、サーバーで利用者・権限を確認する別の保護されたアプリへ接続する必要があります。
- 過去のコミットにあった架空管理デモはGit履歴に残ります。実データや秘密情報を履歴に追加してはいけません。

既存HP、DNS、メール設定は変更していません。
