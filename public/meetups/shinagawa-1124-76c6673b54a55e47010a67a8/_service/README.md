# 品川ディスカッションの投稿API

参加者の画面は GitHub Pages、投稿の保存先は既存の Cloudflare Worker と D1 です。このディレクトリには稼働中のAPIのソースと、データベース構造を再現するSQLを収録しています。

| API | 用途 |
| --- | --- |
| `/api/ideas` | 個人案を投稿・取得する |
| `/api/themes` | 班や会場のテーマを投稿・取得・更新する |
| `/api/reactions` | 賛同のリアクションを記録・取得する |
| `/api/comments` | 個人案・テーマへのコメントを投稿・取得する |

通常のリクエストは本番会場を使い、練習会場は `?room=demo` で指定します。

- `app/api/` が4つのルートと入力・アクセス検証を担います。
- `app/worksheet.ts` と `app/post-analysis.ts` は記入欄の定義、タイトルと要約の抽出に使います。
- `db/` が D1 バインディング `DB` とテーブルを定義します。
- `drizzle/` の番号付きSQLを順に適用するとスキーマが再現されます。`meta/` はスキーマ変更の生成履歴です。

画面の公開とAPIの反映は別です。APIを変更したときは既存Workerのリリース手順で反映します。マイグレーションには新規テーブルと列、インデックスの定義だけが含まれます。
